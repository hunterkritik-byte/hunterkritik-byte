## ⚡ HUNT SIFT

**Offline-first security artifact analysis for controlled research.**

| Module | Capability |
|---|---|
| `HTTP` | Raw request / response review |
| `BURP` | Burp XML artifact analysis |
| `HAR` | HTTP Archive analysis |
| `SOURCE` | JavaScript / source review |
| `BOLA` | Authorization / IDOR review cues |
| `INJECTION` | SQL / NoSQL indicators |
| `REPORT` | Aggregation + JSON + SARIF |
| `WORKSPACE` | Case inventory + SHA-256 fingerprints |
